# DETAIL FORM

Демонстрационный проект Ивана Рудченко. Студия вымышленная.

Статический сайт на HTML, CSS и JavaScript. Открывается через index.html. Форма демонстрационная: данные никуда не передаются и не сохраняются.

GitHub Pages: ветка main, каталог /(root). В экспортной версии изображения и шрифты находятся рядом с HTML для загрузки через интерфейс GitHub. Исходный проект сохраняет структуру assets/.
